# 다르샨 그린 컬렉션 — 프리미엄 에디토리얼 버전 (쿠팡·네이버)

`../darshan-green-collection`(1차 버전)과 같은 내용과 사진을 쓰고, 인센스 전문 브랜드와 고급 프래그런스 브랜드의
상세페이지 스타일을 참고해 다시 디자인한 버전입니다.

## 참고한 스타일
- **나그참파코리아** (29CM 상세페이지): 따뜻한 크림 톤, 세리프 영문 타이틀, 연기 모티프, 차분한 무드
- **그랑핸드** (공식 온라인 스토어 상품 페이지): 오프화이트 배경, 넉넉한 여백, 작은 글씨, 향을 장면처럼 묘사하는 문장
- 헤븐센스는 공식 상세페이지를 찾지 못해 참고하지 못했습니다.

참고 브랜드의 이미지·일러스트·문구는 사용하지 않았고, 분위기와 구성 방식만 참고했습니다.

## 구성
1. 커버: 딥 그린 배경, 세리프 타이틀, 상자 뒤에서 피어오르는 향 연기, 핵심 수치
2. 프롤로그: 6팩 사진 + 향 목차
3. 향 스토리 6장: 팩 색을 흐리게 펼친 배경 + 팩 일러스트 카드 + 향 이름·팩 문구(ON THE PACK)·문장·무드·추천 순간
4. 리추얼: 사용 방법 3단계 (향 스틱 일러스트와 연기)
5. 박스: 보정한 박스 사진 + 디테일 2컷
6. 추천 대상 / 제품 정보 / 구매 전 안내

## 업로드용 결과물 (`output/`)
| 폴더 | 용도 | 가로 |
|---|---|---|
| `coupang_780/` | 쿠팡 | 780px |
| `naver_860/` | 네이버 스마트스토어 | 860px (장당 세로 2,500px 이하) |

각 폴더: `00_full.jpg`(전체 1장) + 분할 9장(01~09, 순서대로 업로드). 섹션 중간이 잘리지 않게 섹션 단위로 묶었습니다.

## 만든 방법
- `src/asset-prep/premium_assets.py`: 1차 버전의 보정 사진에서 향별 배경(블러·톤·그레인)과 팩 일러스트 카드를 만들고,
  카드와 박스 디테일은 Real-ESRGAN(ncnn, CPU)으로 4배 업스케일
- `src/smoke.py`: SVG 노이즈 필터로 그린 향 연기 (커버·리추얼)
- `src/build.py`: 향 데이터(`SCENTS`)로 챕터 생성, 폰트(Noto Serif KR, Noto Sans KR, Cormorant Garamond) 내장
- `src/export.py`: 780/860px 렌더링 후 분할 저장

## 다시 만들기
```bash
python3 src/build.py && python3 src/export.py
```
문구는 `src/template.html`, 향별 문장·무드·추천 순간은 `src/build.py`의 `SCENTS`에서 수정합니다.
